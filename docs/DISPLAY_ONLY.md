# DISPLAY ONLY: cosmetic labels are not analysis labels

The separately named display companion fills enclosed gray holes, closes narrow gaps, smooths coverage and categorical label scores, and interpolates a dense presentation mesh. It deliberately overrides geometric exclusions for appearance, including the retained Group04 holes. All 124 labels per hemisphere remain visible.

This may alter apparent ROI boundaries, size, coverage and component structure. It is intended only for figures, slides and visual demonstrations. Never use its labels or masks for ROI extraction, morphometry, connectivity, registration, statistics or other downstream computation. It contains no T1-space volume atlas. The original v4 analysis package remains unchanged.

Its PNGs are explicitly marked DISPLAY ONLY. The dense mesh has 519,842 vertices per hemisphere and is a two-step interpolation from 32,492 vertices; no new MRI information is created.
